## 💡 Instructor Notes

### Key Teaching Points

1. **LLMs are stateless** - Hammer this home
2. **Tool calling = magic** - Show the loop clearly
3. **Mock devices = learning tool** - Emphasize production path
4. **Agents decide strategy** - Not hardcoded logic

### Common Pitfalls to Address

1. **Context window confusion** - Draw diagrams
2. **Tool schema importance** - Show bad vs. good
3. **Mock vs. real** - Explain the swap
4. **Agent hallucinations** - Show error handling

### Time Management

- Labs tend to run 5-10 minutes over
- Build in 15min buffer
- Can condense theory if needed
- Lab 4 is non-negotiable (35 min minimum)

### Backup Plans

**If WiFi fails:**
- All labs work offline with Ollama
- Pre-download models
- Have local API proxy

**If API keys fail:**
- Use Ollama for everything
- Show pre-recorded demos
- Share your API key temporarily

**If attendees fall behind:**
- Provide working code for each lab
- Jump ahead to Lab 4 (the star)
- Make Lab 4 self-contained
